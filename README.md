
# grassmessage
[![](https://jitpack.io/v/user11117s/grassmessage.svg)](https://jitpack.io/#user11117s/grassmessage)

grassmessage is a small XML-based message builder for constructing Adventure components in Java.
It relies on a schema, allowing for autocomplete of text components in editors.

Get started with the library [here](docs/formed/GettingStarted.md)!
